# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique code rather than people, and keep discussions on topic. Harassment, insults and discriminatory language aren't tolerated.

Report unacceptable behavior privately to the maintainer via a [private security advisory](https://github.com/philppplik/broom/security/advisories/new) or by contacting [@philppplik](https://github.com/philppplik). Reports are handled confidentially.
